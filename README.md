# Bracelet Builder — Next.js App

The core Next.js 16 application for the Beadu × Froyo bracelet customizer.

## Development

```bash
npm install
npm run dev        # → http://localhost:3000
npm run build      # Production build
```

## Key Pages

- `/` — Landing page with preset designs
- `/builder` — 3-step bracelet customizer (Select → Design → Review)
- `/admin/orders` — Admin order dashboard
